# Healthcare-Project_Wellness-Hospital-Performance-Analysis
This project focuses on analyzing the performance of Wellness Hospital to derive outcomes from patient analysis, revenue and admission trends, treatment analysis, Financial analysis and doctors performance across 500 patient records, 5 medical departments and 4 regional branches.

This repository contains a complete healthcare data analytics project for Wellness Hospital. Operating as a Data Analyst, the primary objective was to clean, model, analyze, and visualize a multi-branch healthcare dataset to uncover operational inefficiencies, financial growth levers, and clinical performance insights.

The project features an interactive, multi-page Power BI dashboards and a PDF report providing analytical findings and strategic business recommendations to enable the business make better decisions and improve overall performance.
